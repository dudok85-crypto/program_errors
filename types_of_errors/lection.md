# Виды ошибок программного обеспечения и их отладка

**Ошибка (bug)** - Ситуация при которой программа ведёт себя не так, как того требует ожидание или спецификации.<br>

**Сбой/Исключение (exeption)** - Событие в процессе выполнения программы, которая нарушает нормальный поток управления.
> В Python исключение - это объект, который можно перехватывать и обрабатывать. <br>

**Дефект (defect)** - Несоответсвие между ожидаемым и практическим поведением программы.

### Причины появления ошибок

1. Ошибки проектирования (неверная логика алгоритмов).<br>

`NameError`
```py
print(irg)
```
`TypeError`
```py
a = 10
b = '20'
print(a+b)
```
`ValueError`

```py
x = int('abc')
print(x)
```
`AttributeError`
```py
string = 'hi'
string.append("!")
```
2. Синтаксические ошибки.<br>

`SyntaxError`
```py
x = 1
if x >= 5
    print('Число больше пяти')
```
3. Неучтённые граничные случаи. (пустые списки, деление на ноль и т.п.).<br>

`IndexError`
```py
list = [1,2,3]
print(list[5])
```

`KeyError`
```py
data = {
    'name': 'Alice',
    'city': 'Moscow'
}
print(data['age'])
```
`ZeroDivisionError`
```py
print(10/0)
```
4. Несогласованность формата данных. (строка вместо чиса и т.д)<br>

`TypeError`
```py
a = 10
b = '20'
print(a+b)
```
5. Внешние факторы (потеря файлов, сетевые сбои, неполадки оборудования.)<br>

`FileNotFoundError`
```py
with open('example.txt', 'r',encoding='utf-8') as f:
    content = f.read()
```

### Обработка исключений: Конструкция try/except/else/finally

* **`try`**: Участок кода, где может возникуть ошибка.<br>

* **`except`**: Реакция на конкретный тип исключения, можно использовать несколько блоков except.<br>

* **`else`**; Выполняется только если в `try` не было исключений. Удобно использовать для создания кода. который должен работать только при отсутствии ошибок и исключений.<br>

* **`finally`**: Выполняется всегда, даже при наличии исключений. Используется для освобождения ресурсов для программы.

> Блоки `else` и `finally` не является обязательными конструкциями.

```py
try:
    # Код, который может вызвать исключения 
    result = 10/int(input('введите число: '))
except ZeroDivisionError:
    # Обработка исключений деления на ноль 
    print('[Ошибка]: Обнаружено деление на ноль.')
except ValueError:
    print('[Ошибка]: Необходимо ввести число.')
else:
    # Выполняется, если исключений не было.
    print(f'Результат: {result}')
finally:
    # Выполняется всегда, даже при наличии исключений.
    print('Программа завершена.')
```

## Отладка ошибок программного обеспечения

**Отладка (debugging)** - это процесс поиска локализации и устранения ошибок в программном коде.

### Отладка с использованием `print()`

Самый простой и распространённый способ отладки предуспатривающий добавление вызовов функции `print()` ключевые точки входа. (Просмотр промежуточных результатов)

```py
def calculate_discount(price, sale):
    discont = price*sale/100
    print(f'Сумма скидки: {discont}')    # Отладочный вывод
    final_price = price-discont
    print(f'Итоговая цена: {final_price}')
    return final_price

""" Ожидание: Цена - 1000, скидка 10% """
calculate_discount(1000,10)
```

### Использование `{x=}`

Начинаем с версии Python 3.8+ в F-строках можно использовать не только запись `{x}`, но и `{x=}` которая автоматически выводит и имя переменной, и её значение.

```py
x, text = 42, 'hihihaha'
print(f'{x=}\n{text=}')
```

```py
def calculate_discount(price, sale):
    discont = price*sale/100
    print(f'Сумма скидки: {discont=}')    # Отладочный вывод
    final_price = price-discont
    print(f'Итоговая цена: {final_price=}')
    return final_price

""" Ожидание: Цена - 1000, скидка 10% """
calculate_discount(1000,10)
print
```

```py
def a_b(a,b):
    return a+b

print(f'Сумма чисел: {a_b(10,20)=}')
```

### Модуль `logging`

По мере роста и усложнения проекта использование `print` или `{x=}` становится неудобным, рутинным, трудным. (НЕобходимо постоянно включать и выключать, нельзя направить файл  не всегда понятна в терминале, откуда приходит сообщение)
Для решения таких задач разработан встроенный бодуль `loging`

Модуль `logging` поддерживает несколько уровней важности сообщений. 

|Уровень|Функция|Когда использовать|
|-|-|-|
|DEBUG|`logging.debug()`|Подробная отладочная информация|
|INFO|`logging.info()`|Подтверждение нормальной работы|
|WARNING|`logging.warning()`|Предупреждение и незначительные ошибки|
|ERROR|`logging.error()`|Ошибки, не позволяющие выполнить программу|
|CRITICAL|`logging.critical()`|Критические ошибки, при которых программа не может начать или продолжить работу|

```PY
import logging

# Базовая натсройка; Уровень DEBUG, вывод в консоль
logging.basicConfig(
    level=logging.DEBUG,
    format="%(asctime)s, | %(levelname)s | %(message)s"
)

logging.debug(f'Отладочное сообщение')
logging.info('программа запущена')
logging.warning('Некоректнные входные данные')
logging.error('Файл не найен')
logging.critical('Критический сбой системы')
```

Вывод: 
```

2026-09-22 13:58:23,864, | INFO | программа запущена

2026-09-22 13:58:23,865, | ERROR | Файл не найен
```

Запись логов в отдельный файл: 

```py
"""Запись логов в файл"""

import logging
logging.basicConfig(
    filename='app.log', # Имя файла, в который будут записываться логи.
    level=logging.DEBUG, # Минимальный уровень
    format="%(asctime)s, | %(levelname)s | %(message)s",
    encoding='utf-8' # Кодировка кириллицы
)
# Реализация

logging.info('Программа запущена')
logging.debug('Значение переменной x = %x', 34)
```

Содерживое файла после выполнения кода: 

Основный приемущества `logging` перед `print`. 
* Можно включать и выключать уровни отладки одним параметром, без удаления строк.
* Сообщения можно направлять в файл без изменения кода логирования.
* Каждая запись автоматически получает временную метку и уровень важности.


### Оператор assert 
assert - Инструмент для проверки предположений и гипотиз разработчика, относительно реузльтата работы программного кода.

Принцип работы `assert`; если условие истинно, но ничего не происходит, если ложно - программа прерывается с ошибкой.

Код: 

```py
def calculate_bmi(weight, height):
    # Проверка: вес и рост должны быть больше 0
    assert weight>0, 'Вес должен быть положительным числом'
    assert height>0, 'Рост должен быть положительным числом'

    bmi = weight/(height**2)
    return round(bmi,1)

# Реализация 

print(calculate_bmi(-65, 1.68))
```
Важным нюансом использования `assert` является использвоание флага `-O`:

```
python -O work.py
```

Запуск Python файла с флагом -O обойдёт ошибки связаные с `assert`. Поэтому ни в коем случае нельзя использовать `assert` для проверки данных, полученных от пользователя или внешних источников. Для таких првоерок нужен if c обработкой ошибки.
